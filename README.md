# self-quant-pro

第三代个人量化研究与交易系统。当前阶段：**G1 · 数据层**（以根目录的 `STAGE` 文件为准）。

这一代先打一层底：把"不骗自己"的规则写成代码，由持续集成替人把关。研究、数据、模型、实盘都建在这层规则之上。

## 和前两代的关系

前两代（myquant、finance-research）只作参考，不搬代码。只继承三样丢了就找不回来的东西：试验记录、数据的分段边界、没被看过的数据。继承的内容固定在 `registry/inherited/`，任何人都能按记录的提交重新生成、逐字节核对。详见 [代际传承](docs/lineage.md)。

## 规则怎么执行

| 规则 | 执行方式 |
|---|---|
| 账本只追加 | 与目标分支逐字节比对，外加哈希链 |
| 冻结文件、阶段只能一步一步走 | 改动必须在同一个 PR 附上新的决策记录 |
| G7 之前没有下单代码；任何阶段都没有提币和资金划转代码 | 代码扫描 |
| 数据、密钥不进仓库 | 文件扫描、密钥扫描（含 PR 里每一次提交） |
| 假说注册后冻结，阈值只能更严 | 注册表检查 |
| 前代看过的数据要声明 | 研究宇宙的暴露检查 |

合并进 `main` 之后，PR 由 `main` 上的检查器把关（`gate` 工作流），PR 自己改不了闸门。

本地运行：`uv run sqp check --base origin/main` 和 `uv run pytest`。
