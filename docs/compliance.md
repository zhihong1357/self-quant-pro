# 合规

本系统面向国际通用：不写死任何一个国家的规则。每次涉及实盘或资金，都按**所有者当时的居住地**和**所用的交易场所**重新核对。这里列的是必须核对的事项，不是法律意见。

## 1. 任何阶段都适用

- **公开仓库里不放**：账户标识、个人信息、密钥、第三方原始数据、WorldQuant BRAIN 的任何内容。
- **BRAIN 隔离**：BRAIN 顾问协议有保密要求。alpha 表达式、数据字段、模拟结果只留在 BRAIN 平台上，不进本仓库，也不拿来当本系统的研究输入。
- **数据条款**：每个数据源登记时写明它的条款允许什么（研究、发表结果、实盘）。不确定就当作不允许。
- **派生结果**：由第三方数据算出的数值（试验指标、数据画像、报告、预测）不进公开仓库，放在私有存储桶；仓库只记指纹（[决策 0011](decisions/0011-derived-results-stay-private.md)）。

## 2. 实盘之前必须核对的六件事（G7 进入条件的一部分）

| # | 事项 | 怎么核对 | 结果写在哪 |
|---|---|---|---|
| 1 | 交易场所对账户持有人当时的居住地开放，并且在当地合法 | 交易场所自己的限制地区名单；当地金融监管机构公开的警示名单 | 决策记录 |
| 2 | 只用所有者本人的账户和本人的钱 | — | 决策记录 |
| 3 | 产生实盘信号的每个数据源，条款允许实盘用途 | 逐个读条款（Binance 公开数据站目前不允许） | 数据源登记 |
| 4 | 产品适当性：当地对零售客户的杠杆上限、衍生品限制 | 交易场所在该地区的规则页面 | 决策记录 |
| 5 | 税务记录：每一笔成交、手续费、资金费都留在账本里 | G7 的对账流程 | 账本 |
| 6 | 交易所密钥只开交易权限、关闭提币、绑定 IP 白名单，存放在 Secret Manager | 交易所的密钥设置页面 | 决策记录 |

居住地变了（例如搬到另一个国家），第 1、4、5 项全部重做，然后才能继续实盘。

## 3. 别人的钱（G8）

替别人管理资金，几乎在所有地方都是受监管的业务。在取得所在地的法律意见和必要的牌照之前：

- 不接受任何外部资金，不代别人操作账户，不做收益分成。
- 可以做的：公开、带时间戳、不收费的前向记录，用来证明结论是事先写下的，而不是事后挑出来的。

## 4. 密钥泄露时

1. 立刻到服务商那里作废这把密钥，生成新的。
2. 检查这把密钥在泄露期间有没有被使用过。
3. 从仓库里删掉它只是第三步：推送过的内容已经公开，删除不能撤回。
4. 写一份决策记录：怎么泄露的、怎么防止再发生。
