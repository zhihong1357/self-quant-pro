# 术语表

| 术语 | 意思 |
|---|---|
| 夏普比率 | 收益除以波动。年化夏普 1 大致是"一年赚的钱等于一年里的典型波动" |
| t 统计量 | 结果离"纯属运气"有多远。约等于年化夏普 × √年数。本系统默认要 ≥ 3 |
| 功效 | 如果优势真的存在，检验能把它找出来的概率。本系统要 80% |
| 最小可检测效应 | 在给定的样本长度和功效下，能被可靠检测到的最小夏普。`sqp power` 算的就是它 |
| 多重检验 | 试的次数越多，越容易碰巧撞上一个好看的结果 |
| 折损夏普 | 把"试了多少次"考虑进去之后的夏普显著性，用概率表示 |
| 回测过拟合概率（PBO） | 从多组参数里挑出来的最好那组，在样本外表现落到中位数以下的概率 |
| 前视偏差 | 回测里用到了当时还不知道的信息 |
| 时点数据 | 按"在那个时刻能知道什么"来查询的数据，修订前的值和修订后的值分开存 |
| 幸存者偏差 | 只看到活下来的品种（比如没包括已下架的币），结果会偏好 |
| 研究宇宙 | 一起研究、一起交易的一组品种，例如 U1：加密货币 USDT 永续合约 |
| 探索集、确认集、金库、前向 | 研究宇宙按时间切成的四段，见[科研规程](protocol.md)第 2 节 |
| 暴露 | 某段数据已经被某一族假说看过、用掉了 |
| 假说族 | 机制相同或相近的一组假说，共享试验计数和暴露 |
| 证据等级 E0–E5 | 一条结论被证明到什么程度，见[科研规程](protocol.md)第 4 节 |
| 边际贡献 | 一个信号加进整体模型之后，整体变好了多少 |
| 广度 | 同时进行、彼此独立的下注数量。广度越大，同样的单次预测质量能换来越高的夏普 |
| 容量 | 一个优势能容纳多少资金而不被交易成本吃掉 |
| 市场冲击 | 自己的成交把价格推向不利方向的成本，成交越大越明显 |
| 永续合约 | 没有到期日的期货，靠资金费率让价格贴近现货 |
| 资金费率 | 永续合约多空双方之间定期互相支付的费用 |
| 不爆仓约束 | 无论发生什么（跳空、交易所停摆），单个账户的损失都不超过事先写下的上限 |
| 熔断 | 触发条件（日内亏损、对账不符、数据中断）出现时自动停止交易 |
| 哈希链 | 每条记录都带着上一条的指纹，改动任何旧记录都会被发现 |
| 冻结文件 | 合并之后不能再改的文件；确需改动要附一份决策记录 |
| 决策记录 | `docs/decisions/` 里的一份文件，记录一个决定、它的背景和后果 |
| PR（拉取请求） | 一组改动，经过检查和所有者合并才进入 `main` |
| 持续集成（CI） | 每次有改动时，GitHub 自动运行的检查 |
| Workload Identity Federation | 让 GitHub 不用长期密钥就能部署到谷歌云的身份机制 |
