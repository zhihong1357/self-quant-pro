## 2. 继承什么：三样不可再生的东西

代码可以重写，下面这些丢了就找不回来。

| 不可再生的东西 | 为什么 | 在第三代的位置 |
|---|---|---|
| 试验记录 | 多重检验的折损要算上所有试过的次数，包括失败的 | `registry/inherited/`：原样复制的试验账本，加上 `trials.json` 的分类与计数 |
| 数据的分段边界 | 边界一旦重新切，等于再掷一次骰子 | `registry/universes/U1.toml`，冻结 |
| 没被看过的数据 | 看过的数据不能再当检验用 | U1 的 `[exposure]`：哪些假说族已经用掉了确认集和金库 |

另外，第一代录下的、无法重新获取的原始数据也属于不可再生的东西。它们不能进公开仓库，G1 导入原始层：

| 数据 | 起始 | 所在 |
|---|---|---|
| Deribit 全量期权每日快照（BTC、ETH） | 2026-10-26 | fakeout-backtest |
| Deribit GEX 快照 | 2026-10 | orderflow 的 `gex-data` 分支 |
| 基差、资金费率、期权平价、美股期权流指标的定时快照 | 2026-11-12 | orderflow 的 `lab-data` 分支 |

**怎样核对继承**：`registry/inherited/manifest.json` 记下了两个第二代仓库的固定提交，以及 198 个文件的 SHA-256、字节数和行数。`uv run sqp inherit verify` 会在临时目录里按这两个提交重新取出代码、重新生成，逐字节比对；持续集成每周跑一次。

## 4. 怎样才算超越：迁移验收

"超越"不是更多代码，是三条可以检验的条件，全部满足才算：

**A. 重现。** 在第三代的框架里，从原始数据重新算出第二代的两个结论：myquant 的 btc-eth-001（BTC/ETH 跨市场传导，被否定）和 finance-research 的 H-0001（合成数据的时点细线，相关系数的置信区间包含理论值 0.349）。结论一致，关键指标的差异在一个标准误以内。G2 完成。

**B. 补上前代没有的能力。**

| 能力 | 第二代 | 第三代 |
|---|---|---|
| 跨代试验计数、数据暴露检查 | 没有 | G0 已有 |
| 闸门从 `main` 运行，PR 改不了 | 没有 | G0 已有 |
| 注册前的功效门槛 | 有文字，没有工具 | G0 有工具，G2 起强制 |
| 容量曲线与最佳资金区间 | 原则里有，没做出来 | G4 |
| 生产部署与花费上限 | 没有 | G5 |

**C. 复杂度预算。** 每个阶段结束时记下代码行数和依赖数量。基线：finance-research 的 `src` 约 17,500 行 Python（测试约 14,000 行）、6 个以上运行时依赖；myquant 约 15,200 行 TypeScript。第三代 G0：约 1,250 行 Python、测试约 600 行、0 个运行时依赖。同等功能下第三代应当更小；更大要写理由。

## 5. 前两代的教训

| 教训 | 来源 | 第三代的对策 |
|---|---|---|
| 参数曾经对着个别交易来调整 | 第一代 | 检验方案预注册；参数扰动是必检项 |
| 参数对比没有记录试了多少组 | 第一代 | 试验账本自动记账，折损按账本算 |
| 只存了算出来的指标，没存原始数据 | 第一代 | 原始层只增不改（G1） |
| 一个策略只在一个品种上成立 | 第一代 | 结论登记适用范围；跨宇宙复现是 E3 的条件 |
| 公开仓库里出现过账户标识 | 第一代 | 文件扫描、密钥扫描、推送保护；账户信息一律不进仓库 |
| 两套系统并行，同一批数据各看了一遍，烧掉了部分确认集和金库 | 第二代 | 一个系统、一本账；暴露检查 |
| 基础设施先行太久，研究迟迟没开始 | 第二代（finance-research 停在 Phase 2） | 时间盒和砍掉条件；G2 起必须有真实研究在跑 |
| 两种语言分散了精力 | 第二代 | 只用 Python（[决策 0006](decisions/0006-python-uv.md)） |

## 6. 继承的环境知识

第一代、第二代实测确认过的事实（来自 finance-research 的 `docs/prior-systems.md`，2026-11-12 和 11-13 实测），G1 的采集器直接采用：

- GitHub 的服务器在美国。Binance 的主接口拒绝美国 IP，公开行情改用 `data-api.binance.vision`，历史文件改用 `data.binance.vision`。
- Binance 公开数据站当月的资金费率要到下个月才发布。
- CBOE 延迟期权链的 `timestamp` 字段是 UTC 时间。
- CBOE 期权链里深度实值合约的隐含波动率是无效值，计算前要过滤。
- Yahoo 的行情接口用 `range=max` 会把日线降采样成月线，要改用起止时间参数。
- FRED 的 CSV 接口一次请求多个序列会超时，要一次一个。
- Deribit 的期权和期货在 08:00 UTC 到期。
- Deribit 只覆盖约一半的 BTC 期权持仓，另一半在美股的 IBIT 期权上。
- OKX 的资金费率周期要从接口返回的两个时间戳相减得到，不能假设是 8 小时。Hyperliquid 每小时结算。
