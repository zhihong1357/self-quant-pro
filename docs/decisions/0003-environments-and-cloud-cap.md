# 0003 环境分工，谷歌云每月 10 美元封顶

- 状态：已接受（存储提前到 G1、生产计算的区域到 G5 再定，见 0010；到顶暂停只对按量服务有效、管不了存储，见 0015）
- 日期：2026-11-24
- 提出：所有者（"谷歌云只部署已经确保可以正式上线的部分，不要把测试调试在这边跑"），Claude 补充细节

## 背景

所有者有 Google AI Pro，附带谷歌云赠金和 Colab 额度；可以绑定结算卡，接受每月 10 美元的上限。最大的风险是测试任务或忘记关的机器在云上持续计费。

## 决定

1. 开发和测试在本机、GitHub Actions、Colab。谷歌云只跑已验收的生产任务，从 G5 开始。
2. 预算每月 10 美元，按原价计算（不扣赠金），到顶自动暂停，50%、80%、100% 时提醒。
3. G7 之前不开常驻虚拟机。定时任务用 Cloud Scheduler 加 Cloud Run 作业，跑完即停。
4. 部署只能经过持续集成，并由 GitHub 的 `production` 环境等所有者批准。GitHub 到谷歌云用 Workload Identity Federation，不发长期密钥。
5. 区域用 asia-southeast1（新加坡），数据和计算同区域。

## 后果

- G1–G4 完全免费。
- G5 第一次产生云费用，预计在赠金之内。细则见 `docs/cost-guardrails.md`。
