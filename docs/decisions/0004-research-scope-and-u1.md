# 0004 研究范围多领域开放，U1 沿用第二代的边界

- 状态：已接受
- 日期：2026-11-24
- 提出：所有者（"不需要固定束缚自己只做现货，什么能够赚钱我们就去做什么，开放多元领域"）

## 背景

第二代 finance-research 选了加密永续合约作为第一个研究宇宙 U1（它的决策 0007：免费数据里广度最大），并在 2026-11-15 定下 U1 的分段边界（它的决策 0015，边界记录 B-0001）。

## 决定

1. 研究范围不限现货：永续、期货、期权、宏观、股票等都在范围内。什么能被证明扣成本后赚钱，就研究什么。
2. 每个研究宇宙第一次使用前先定分段边界，写进 `registry/universes/`，之后冻结。新增研究宇宙需要新的决策记录。
3. U1 沿用第二代的定义和边界，不重新切分：探索 2019-12-01 至 2024-01-31，确认 2024-02-01 至 2025-10-31，金库 2025-11-01 至 2026-10-31，前向 2026-11-01 起。
4. 研究里可以用杠杆和衍生品；实盘受 0005 约束。

## 后果

- U1 的确认集只有 21 个月，功效有限：要以 80% 的把握得到 t ≥ 3，年化夏普至少约 2.9（宪章 2.1 节）。研究应当优先选广度大的问题。
- 第二代已经用掉了 U1 部分假说族的确认集和金库，见 0008。
