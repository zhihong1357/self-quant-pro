# 0009 一个统一模型，输出最佳资金区间

- 状态：已接受
- 日期：2026-11-24
- 提出：所有者（"做一个通用的万能模型即可，还有一些成本资金体量的模型去适配最佳资金范围"）

## 背景

所有者的资金将来会变，甚至可能拿项目去找资金，所以不能把系统绑定在某一个本金数字上。小资金的结构性优势恰恰在容量小的地方，而优势一放大就消失。

## 决定

1. 所有研究产出信号，进入同一个模型（继承第二代原则 13）。
2. 成本模型和容量曲线是模型的一部分，不是附录。
3. 不预设本金。模型输出：净收益最好的资金区间，以及优势消失的资金上限。
4. E3 及以上的结论必须附容量曲线（`docs/protocol.md` 第 8 节）。
5. 模型和报告按"任何资金规模都能回答"来设计；但接受外部资金本身受 G8 的法律条件约束（`docs/compliance.md` 第 3 节）。

## 后果

- G4 是第一次产出资金区间的阶段。
- 回答"能赚多少"时，答案总是一条曲线，而不是一个数字。
