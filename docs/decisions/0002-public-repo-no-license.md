# 0002 仓库暂时公开，不附开源许可

- 状态：已接受（第 4 条改为"继续公开、G4 不再重议"，见 0010）
- 日期：2026-11-24
- 提出：所有者（"暂时先公开，关于金钱等的 API 部分都是自己保管"）

## 背景

公开仓库可以免费使用 GitHub Actions 的标准运行器和推送保护，过程也透明。风险是密钥、账户信息或受条款限制的数据被公开。

## 决定

1. 仓库暂时公开。
2. 不附开源许可：代码公开可见，保留所有权利。
3. 任何阶段都不进仓库：密钥、账户信息、资金信息、第三方原始数据、WorldQuant BRAIN 的任何内容。由 `sqp check`、推送保护和人工审查共同执行。
4. G4 结束时重新决定公开还是私有：那时会有模型和容量的结论，可能涉及将来找资金。

## 后果

- 转为私有会失去免费的 Actions 用量和部分免费安全功能，届时要重新评估成本。
- 公开的历史无法撤回。推送过的东西，即使删掉也要当作已经公开。
