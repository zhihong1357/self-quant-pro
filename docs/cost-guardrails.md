# 成本护栏

目标：G1–G4 完全免费；G5 起谷歌云的花费不超过每月 10 美元，并且最好全部由 AI Pro 附带的赠金覆盖。

## 1. 硬规则

1. **谷歌云只跑生产。** 测试、调试、试跑一律在本机、GitHub Actions、Colab。
2. **预算上限 10 美元/月**，到顶自动暂停；50%、80%、100% 时发邮件提醒。预算选"按原价计算、不扣赠金"，这样上限正好等于每月赠金，自己不用掏钱。
3. **G7 之前不开常驻虚拟机。** 日频和小时频的任务用 Cloud Scheduler 触发 Cloud Run 作业，跑完即停。多数策略到 G7 也不需要常驻机器。
4. **数据和计算同一个区域**（asia-southeast1），避免跨区流量费。
5. **每个 BigQuery 查询设扫描上限**；存储桶设生命周期规则；镜像仓库设清理策略。
6. **不申请静态外网 IP**，除非 G7 的交易所 IP 白名单确实需要，并写进决策记录。

## 2. 已经核实的数字

建仓库前（2026-11）的调研。G5 开通前要按当时的官方价格页再核对一次。

| 项目 | 数字 |
|---|---|
| AI Pro 附带的 Google Developer Program 谷歌云赠金 | 每月 10 美元，需要先绑定结算账号再领取 |
| Cloud Run 免费额度 | 每月 18 万 vCPU 秒 |
| BigQuery 免费额度 | 每月查询 1 TiB、存储 10 GiB |
| 外网 IPv4 地址 | 每小时 0.005 美元，约每月 3.65 美元；静态 IP 在机器关机时也收费 |
| e2-micro 免费虚拟机 | 只在美国的几个区域有，不在新加坡 |
| GitHub Actions | 公开仓库的标准运行器免费 |

待复核（置信度中）：Cloud Storage 的免费额度据了解只在美国区域提供，新加坡区域按量收费，但几个 GB 的费用在每月几美分的量级。

## 3. 开通谷歌云时的步骤（G5，所有者做）

到时候由智能体按当时的界面写出逐步点击的说明。大致顺序：

1. 领取 AI Pro 附带的谷歌云赠金，绑定结算账号。
2. 建一个只给本项目用的谷歌云项目。
3. 设预算：10 美元，按原价，开启到顶暂停，三档提醒。
4. 设 Workload Identity Federation，让 GitHub 的 `production` 环境能部署，不发长期密钥。
5. 在 GitHub 建 `production` 环境，审批人设为所有者自己。

## 4. 每月检查（所有者，五分钟）

谷歌云控制台 → 结算 → 报告：看本月花费和赠金余额。超过 5 美元时，让智能体查是哪个服务、为什么。
