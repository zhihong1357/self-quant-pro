# 成本护栏

目标：G1–G4 只有原始数据存储在谷歌云上，费用在免费额度之内或接近零；G5 起计算也上云，总花费不超过每月 10 美元，并且最好全部由 AI Pro 附带的赠金覆盖。

## 1. 硬规则

1. **谷歌云上不测试、不调试。** 测试、调试、试跑一律在本机、GitHub Actions、Colab。G1–G4 谷歌云上只有存储；G5 起才有已验收的生产计算。
2. **预算上限 10 美元/月**，到顶自动暂停；50%、80%、100% 时发邮件提醒。预算选"按原价计算、不扣赠金"，这样上限正好等于每月赠金，自己不用掏钱。
3. **原始数据的存储桶放在 us-central1**，那里有永久免费额度（[决策 0010](decisions/0010-owner-decisions-2026-11-24.md)）。
4. **流出流量是最大的费用风险**（流出到互联网 0.12 美元/GB）。研究任务只读精简后的研究数据集并缓存，不重复整份下载原始层。
5. **G7 之前不开常驻虚拟机。** 日频和小时频的任务用 Cloud Scheduler 触发 Cloud Run 作业，跑完即停。多数策略到 G7 也不需要常驻机器。
6. **生产计算尽量和它读的数据放在同一区域**，同一位置内的数据传输免费。生产计算的区域在 G5 决定。
7. **每个 BigQuery 查询设扫描上限**；存储桶设生命周期规则；镜像仓库设清理策略。
8. **不申请静态外网 IP**，除非 G7 的交易所 IP 白名单确实需要，并写进决策记录。

## 3. 开通谷歌云的步骤（G1 开头，所有者做）

到时候由智能体按当时的界面写出逐步点击的说明。大致顺序：

1. 领取 AI Pro 附带的谷歌云赠金，绑定结算账号。
2. 建一个只给本项目用的谷歌云项目。
3. 设预算：10 美元，按原价，开启到顶暂停，三档提醒。
4. 建存储桶：us-central1，标准存储；给数据采集的服务账号只授予"创建对象"的权限。
5. 设 Workload Identity Federation，只允许本仓库 `main` 分支上的工作流写入，不发长期密钥。
6. G5 时再建 GitHub 的 `production` 环境，审批人设为所有者自己。

## 4. 每月检查（所有者，五分钟）

谷歌云控制台 → 结算 → 报告：看本月花费和赠金余额。超过 5 美元时，让智能体查是哪个服务、为什么。
